# 侧栏视觉规范

源概念图：`side-panel-concept.png`

## 设计方向

- 深炭灰背景，避免视频旁出现高亮白色区域。
- 象牙白正文与克制的玉绿色强调色。
- 当前知识点使用纸质便笺感浅色表面，其余区域保持开放布局。
- 录制状态明显但安静，不使用霓虹、渐变或游戏化元素。

## Tokens

- Background: `#151917`
- Surface: `#1d2421`
- Surface elevated: `#222b27`
- Paper: `#f2eee3`
- Text: `#f1f0ea`
- Muted: `#9da59f`
- Accent: `#8fd0a3`
- Accent strong: `#b0e2bd`
- Border: `rgba(211, 225, 216, 0.16)`
- Radius: `12px`, `16px`
- Spacing scale: `4, 8, 12, 16, 24, 32px`

## 组件

- 顶部品牌栏：品牌名、低调说明、设置按钮。
- 会话状态：录制点、状态、视频标题、计时。
- 当前知识点：单一纸张表面，不堆叠卡片。
- 字幕：时间戳与正文的开放列表，以细分隔线组织。
- 暂停回忆：只在视频暂停且已有内容时出现。
- 底部操作：固定在底部，一个主按钮与两个次按钮。
